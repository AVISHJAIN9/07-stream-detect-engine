# Systems Engineering Glossary: Streaming Anomaly Engine

### Tumbling Window
Fixed-size, non-overlapping temporal partition over a continuous data stream.

### EWMA
Exponentially Weighted Moving Average; statistical metric assigning exponentially decreasing weights to older observations.

### Backpressure
Flow-control mechanism signaling upstream producers to slow emission rate when processing buffers reach capacity.

### Out-of-Order Events
Stream records arriving later than expected due to network jitter, handled using watermarking mechanisms.
